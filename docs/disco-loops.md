# Десять диско-лупов

В папке [`disco/`](disco) лежат десять **оригинальных** танцевальных диско-лупов
по **30 секунд**. Они сгенерированы с нуля этим репозиторием: ни одного сэмпла,
ни одного скачанного трека, ни одной чужой мелодии. Код генерации - в
[`tools/disco_synth.py`](tools/disco_synth.py),
[`tools/disco_loops.py`](tools/disco_loops.py),
[`tools/disco_arrange.py`](tools/disco_arrange.py) и
[`tools/generate_disco_loops.py`](tools/generate_disco_loops.py).

Лупы не входят в игру и не пакуются в APK/EXE: папка `disco/` отдельная, вне
`assets/`, поэтому размер сборки не меняется. Слушать удобнее всего через
[`disco/index.html`](disco/index.html) - проигрыватель со всеми десятью треками
и режимом бесшовного повтора.

## Права

Код и сгенерированные им WAV - собственность проекта (см.
[LICENSE](LICENSE)). Внутри генератора **нет** ни сторонних библиотек, ни
сэмплов, ни заимствованных мелодий: это чистые синусоиды, пилообразные и
шумовые осцилляторы с огибающими, расставленные по нотам вручную. Поэтому треки
не содержат чужих авторских прав «по построению»: всё, что звучит, посчитано
из математики в этом репозитории. Если нужна свободная лицензия для передачи
другу - разрешение выдаёт правообладатель проекта.

## Формат

Все десять файлов одинаковые по формату, чтобы их можно было ставить подряд:
WAV, стерео, 16 бит PCM, 22 050 Гц, ровно 30.000 с (1 323 000 кадров),
около 2.5 МиБ каждый.

## Как сделана бесшовная петля

1. **Круглый микс.** `Mixer.hit()` и `Mixer.sustain()` пишут в буфер с
   заворотом: нота, начавшаяся на 29.9 с, дозвучивает в начале файла. Поэтому
   в конце нет ни затухания, ни обрубленного хвоста.
2. **Нет фейдов.** В отличие от игровых треков (`tools/generate_music.py`),
   здесь нет `fade_in`/`fade_out`: они бы дали провал на стыке.
3. **Целое число тактов.** Темп подобран так, чтобы 30 с были ровно 13-16
   тактами. Стык всегда приходится на первую долю, метрика не ломается.
4. **Подложка сквозь стык.** Пады начинают звучать на 18 % такта раньше нуля
   (`bleed`), поэтому на первом сэмпле уже есть гармония.
5. **Переход в конце.** Райзер стоит за 1.6 с до конца и разрешается ровно в
   первый удар первой доли - повтор звучит как продолжение трека.

## Пересобрать

Нужен только Python 3 (стандартная библиотека, без numpy и без ffmpeg):

```
python3 tools/generate_disco_loops.py            # все десять, ~90 с
python3 tools/generate_disco_loops.py 03_mirrorball_dreams
python3 tools/generate_disco_loops.py --list
```

Генерация детерминированная: один и тот же код всегда даёт те же байты.
Случайность есть только в шумовых ударных, и она зафиксирована зерном.

## Превью

```
python3 tools/disco_preview.py
```

Рисует `disco/preview.png` - по одной осциллограмме на трек (только `wave` и
`zlib`, без картинок-зависимостей). По картинке сразу видно, что все десять
лупов одинаковой громкости, начинаются с полного уровня, не проваливаются в
тишину и держат ровный ритм до самого стыка.

## Проверки

```
python3 tools/test_disco_loops.py
```

Тест проверяет формат и длительность, что при заявленном BPM в файле целое
число тактов, что скачок на стыке не больше обычного шага сигнала (нет щелчка),
что последние 50 мс не тише середины (луп не заканчивается тишиной), что пик не
клиппирует, нет постоянной составляющей, а десять файлов действительно разные.

## Как устроен звук

* **Осцилляторы.** `disco_synth.table()` собирает аддитивные волновые таблицы:
  `strings`, `brass`, `saw`, `square`, `pulse`, `organ`, `clav`, `glass`,
  `choir`, `hollow`, `bass`. Число гармоник ограничено по высоте ноты, чтобы не
  было алиасинга на 22.05 кГц.
* **Огибающие.** `Mixer.sustain()` считает ADSR прямо в буфер, с вибрато и
  расстройкой (`detune`) для ширины стерео.
* **Ударные.** `disco_synth` синтезирует бочку с падением высоты, снейр из шума
  плюс тон, трёхслойный клэп, хэты и шейкер через фильтры, ковбелл, конги, крайм.
  Набор гейн-стейджится по RMS (`disco_loops.kit()`), иначе бочка была бы на
  20 дБ громче хэта и паттерны нельзя было бы свести.
* **Микс.** `Mixer.echo()` - пинг-понг эхо по шине эффектов с заворотом (тоже
  бесшовно), `Mixer.master()` - срез низа, мягкий клип `tanh`, полка «воздух»
  на 2.4 кГц и нормализация RMS. Уровни секций: ударные около -16 dBFS RMS,
  бас -21, пады и хук -22...-23, эффекты -31.
