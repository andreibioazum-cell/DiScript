# One disco loop and three game themes

All music in the repository is **original** and generated by this project: no
samples, no downloaded tracks, no third-party libraries, no borrowed melodies.

Everything lives in one place, split by purpose:

```
assets/audio/
  tracks/            music (4 files)
    lobby.wav        game: ordinary lobby theme, 70 s
    winter_lobby.wav game: New Year lobby theme, 70 s
    duel.wav         game: Azum vs Astra duel theme, 45 s
    disco_01_roller_rink_sunset.wav
                     game: the disco event (event 1), 30 s loop
  sfx/               nine one-shot sounds (punch, dash, grab, gift, station,
                     overclock, zombie_punch, zombie_dash, button_click)
```

The build staging script turns this tree into the layout the game reads:
`sounds/tracks/` for music and `sounds/sfx/` for effects. Both the APK and the
Windows package get exactly that.

## The disco loop

The loop is **30 seconds** of 22.05 kHz stereo 16-bit PCM WAV and wraps
seamlessly: it can be repeated for the whole fight without a click, a gap or a
level dip.

| File | Key | BPM | Bars | Character |
| --- | --- | --- | --- | --- |
| `disco_01_roller_rink_sunset.wav` | A minor | 120 | 15 | warm strings, congas, brass hook |

It is the **first** of the loops written for the project and the only one that
stayed: the event needs one tune, and this is the one picked for it. The game
plays it from `src/game/fx/disco_music.inc` while a fight runs with event 1
("disco"): the lobby, winter and duel themes fade out, the loop fades in over
0.35 s and loops until the fight ends.

The loop also replaces the third-party recording that `main` still bundles
("Disco Medusae" by Kevin MacLeod): nothing in this branch is licensed from
outside, so the credit line, the notice file and the CC BY entry in
`THIRD_PARTY_NOTICES.md` are not needed here.

A preview of the waveform is in [disco-preview.png](disco-preview.png)
(`python3 tools/disco_preview.py` redraws it).

## Why the loops are seamless

1. **Circular mix.** `Mixer.hit()` and `Mixer.sustain()` wrap around the buffer,
   so a note that starts at 29.9 s rings on at the top of the file. No tail is
   cut off.
2. **No fades.** Unlike the game themes, the loops have no fade in or out; a
   fade would put a hole right at the loop point.
3. **Whole bars.** The tempo is chosen so that exactly 15 bars fit in 30 s
   (`BPM = 8 x bars`). The seam always lands on beat one.
4. **A pad across the seam.** The chord bed starts 18 % of a bar before zero
   (`bleed`), so harmony is already sounding on the first sample.
5. **A transition into the seam.** A riser sits 1.6 s before the end and resolves
   exactly on the first kick of the next pass.

## Rebuild

Python 3 only, no numpy, no ffmpeg:

```
python3 tools/generate_disco_loops.py              # the loop, about 12 s
python3 tools/generate_disco_loops.py disco_01_roller_rink_sunset
python3 tools/generate_disco_loops.py --list
python3 tools/generate_music.py                    # the three game themes
```

Generation is deterministic: the same code always writes the same bytes. The
only randomness is in the noise percussion, and it is seeded.

## Checks

```
python3 tools/test_disco_loops.py
```

The test verifies the format and the 30 s duration, that the documented BPM
gives whole bars, that the seam jump is no bigger than the ordinary sample step
(no click), that the last 50 ms are not quieter than the middle (no silence at
the loop point), that the peak does not clip, that there is no DC offset, and
that the file is the one the game plays (`src/game/fx/disco_music.inc`).

## How the sound is made

* **Oscillators.** `disco_synth.table()` builds additive wavetables: `strings`,
  `brass`, `saw`, `square`, `pulse`, `organ`, `clav`, `glass`, `choir`,
  `hollow`, `bass`. The harmonic count is capped by pitch, so nothing aliases at
  22.05 kHz.
* **Envelopes.** `Mixer.sustain()` computes ADSR straight into the buffer, with
  vibrato and detuning for stereo width.
* **Drums.** `disco_synth` synthesises the kick (pitch drop), snare (noise plus
  tone), a three-layer clap, filtered hats and shaker, cowbell, congas and
  crash. `disco_loops.kit()` gain-stages them by RMS, otherwise the kick would
  sit 20 dB above a hat and the patterns could not be mixed.
* **Mix.** `Mixer.echo()` is a wrapped ping-pong echo on the effect bus,
  `Mixer.master()` does DC removal, soft `tanh` clipping, an "air" shelf at
  2.4 kHz and RMS normalisation. Section levels: drums around -16 dBFS RMS,
  bass -21, pads and hook -22..-23, effects -31.
