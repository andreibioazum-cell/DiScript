# Юридический разбор Cubic Battle 4 (РФ), ноябрь 2026

> Не юридическая консультация. Это технический аудит рисков: где код и документы
> расходятся с законом и что дешевле всего исправить. По пунктам с пометкой
> «юрист» — идти к юристу, там штрафы кратно больше стоимости консультации.

## 1. Короткий вердикт

| Блок | Состояние | Оценка |
|---|---|---|
| Документы внутри игры (EULA, политика ПД, согласие, лицензия, права) | 8 страниц, RU+EN, отметка о согласии с датой | **сильно** — лучше, чем у большинства инди |
| Минимизация данных | ник + пароль + прогресс + настройки + чат; почты/телефона/гео нет | **сильно** |
| Удаление и отзыв согласия | кнопка стирает аккаунт и облако | **сильно** |
| Возраст | знак 12+, родительский контроль (PIN на устройстве) | **хорошо**, но не хватает маркировки в магазинах |
| 152-ФЗ: локализация | Firebase (США), первичная запись за рубежом | **провал** (ч. 8 ст. 13.11 КоАП: 1–6 млн ₽) |
| 152-ФЗ: уведомление РКН | не подано | **провал** (ч. 10 ст. 13.11: 100–300 тыс ₽) |
| 149-ФЗ: чат как ОРИ | уведомления нет, логи за рубежом | **провал** (ч. 1 ст. 13.31: 500 тыс–1 млн ₽) |
| Оператор | физлицо, контакт = GitHub issues | **слабо** (нет адреса/почты для официальных обращений) |
| Модерация UGC | фильтр мата + админ-панель, кнопки «пожаловаться» нет | **средне** |
| Права на игру | LICENSE проприетарный, но ТЗ не зарегистрирован | **средне** |

Итог: **по документам мы защищены хорошо, по инфраструктуре — уязвимы.**
Один иск или одна проверка РКН обнуляет всю юридическую работу, потому что
удар придёт не по текстам, а по серверу, на котором лежат ники и чат.

## 2. Что уже сделано правильно (не трогать)

- Согласие оформлено отдельной галочкой до входа, с сохранением даты и ревизии
  (`pdc/pdv` в `settings.dat`) — это доказательство согласия (ст. 6, 9 152-ФЗ).
- Перечень данных в политике закрытый, совпадает с фактическим (`legal_text.inc`,
  стр. 4): ник, хеш пароля, прогресс, настройки, промокод, чат, отметка о согласии.
- Заявлено «нет рекламы, аналитики, трекеров» — и это правда по коду: нет ни
  одного SDK аналитики, ни рекламных вставок.
- Отзыв согласия = удаление аккаунта (`account_delete.inc`), срок ответа указан.
- Лицензия проприетарная, сторонние компоненты перечислены (`THIRD_PARTY_NOTICES.md`,
  шрифт ComicRelief — OFL, лицензия шрифта лежит рядом с `.ttf`).
- Покупок за деньги нет → не работают 38-ФЗ (реклама), правила возвратов,
  требования к платежам и лутбоксам. Это огромное преимущество, его стоит
  сохранять как можно дольше.
- Родительский контроль (PIN + режим 1–10 / 11–13 / 14+, PIN только на устройстве)
  — это и репутационно, и по духу 436-ФЗ, и заодно минус персональные данные
  (возраст ребёнка никуда не уходит).

## 3. Провалы, которые надо закрыть (по приоритету)

### P0-1. Первичная запись ПДн за границей (локализация)

Что сейчас: `NET_FIREBASE_URL` → `cubicbattleserver-19ae2-default-rtdb.firebaseio.com`,
вход через `identitytoolkit.googleapis.com` (Google Auth). Ник, хеш пароля,
прогресс и сообщения чата пишутся сразу в США.

Норма: ст. 18 ч. 5 152-ФЗ в редакции 420-ФЗ от 30.11.2024 — с 1 июля 2025
**первичный** сбор/запись/систематизация/хранение ПДн россиян допускаются
только в базах на территории РФ. Копия за рубеж возможна, но только после
записи в РФ и по правилам ст. 12 (трансграничная передача).

Ответственность: ч. 8 ст. 13.11 КоАП — 1–6 млн ₽ (ИП/юрлица), ч. 9 — 6–18 млн ₽
при повторе; для гражданина — меньше, но состав есть. Плюс предписание
Роскомнадзора и запись в реестр нарушителей.

Что делать: перенести базу в РФ (Yandex Cloud, VK Cloud, Selectel, свой VPS в
Москве/СПб). Технически это одна точка: `src/engine/network/http_json.inc`
(базовый URL) + `auth_session.inc` (вход). Схема «Россия — основная база,
зарубежная — только копия для чтения» допустима, схема «зарубеж — основная» нет.

### P0-2. Нет уведомления в РКН об обработке ПДн

Норма: ст. 22 152-ФЗ. С 30 мая 2025 неподача — отдельный состав,
ч. 10 ст. 13.11 КоАП: 100–300 тыс ₽ (ИП/юрлица), 30–50 тыс ₽ (должностные),
5–10 тыс ₽ (граждане).

Что делать: подать через сайт РКН (бесплатно, 15–30 минут): оператор, цели,
перечень данных, место хранения (указать российский ЦОД после P0-1), меры
защиты. Пока база за рубежом — подавать бессмысленно, там будет ложь в
уведомлении. Порядок: сначала сервер, потом уведомление.

### P0-3. Чат = организатор распространения информации (ОРИ)

Что сейчас: игроки обмениваются текстовыми сообщениями через сервер — это ровно
признак ОРИ по ч. 1 ст. 10.1 149-ФЗ, независимо от размера аудитории.

Обязанности: уведомить РКН (97-fz.rkn.gov.ru), хранить на территории РФ сведения
о фактах приёма/передачи сообщений и данные пользователей (1 год, по
разъяснениям последней редакции — до 3 лет), давать их уполномоченным органам.

Ответственность: ч. 1 ст. 13.31 КоАП — 500 тыс–1 млн ₽ (юрлица), повторно до
6 млн ₽; отдельно ч. 2 — за нехранение/невыдачу.

Что делать: (а) уведомление ОРИ после переезда в РФ-ЦОД; (б) лог чата хранить
в РФ, а не в Firebase; (в) если не хочется статуса ОРИ — убрать свободный чат
(оставить набор фраз/эмодзи). Это радикально, но легально и дешевле.

### P0-4. Нет публичного оператора и политики по URL

Сейчас оператор — «Дима Густенёв», обращения — GitHub issues
(`legal_text.inc`, `LEGAL_OPERATOR_RU` / `LEGAL_CONTACT`).

Проблема: 152-ФЗ требует, чтобы оператор был идентифицируем, а политика —
доступна (ч. 2 ст. 18.1). Магазины приложений (RuStore, Google Play) требуют
публичный URL политики конфиденциальности; GitHub issue — не канал для
официальных обращений субъекта ПДн и не адрес для РКН.

Что делать: страница `privacy.html` на своём домене (можно GitHub Pages) +
контактный e-mail вида `privacy@…` + почтовый адрес для корреспонденции.
В приложении оставить те же тексты, но с ссылкой на URL.

### P1-1. Возрастная маркировка

Норма: 436-ФЗ, классификацию до начала оборота делает распространитель сам
(ст. 6). 12+ у нас обоснован: бои без крови, нет мата после фильтра, нет
алкоголя/табака/ставок. Знак в игре есть (`legal.inc`, `tr_age_mark`).

Чего нет: знака и описания содержания на странице приложения в магазине (это
обязанность распространителя), а также внутреннего «паспорта классификации» —
документа, которым можно отбиться от претензии.

Ответственность: ст. 6.17 КоАП — 20–50 тыс ₽ (юрлица) / 5–10 тыс ₽ (ИП) с
конфискацией, плюс предписание и риск блокировки по ст. 15.1 149-ФЗ.

Что делать: карточка магазина — «12+», в описании честно перечислить: сцены
боёв без крови, онлайн-чат с фильтром, внутриигровые покупки отсутствуют.
Внутренний документ на 1 страницу с датой и подписью — в `docs/`.

### P1-2. Модерация UGC и «информационный посредник»

Чат и ники — пользовательский контент. Сейчас есть фильтр (`chat_filter.inc`),
замена ников на `***`/`X***` и админ-панель, но нет механизма жалоб и нет
фиксации, что мы реагируем.

Правовая защита: ст. 1253.1 ГК (информационный посредник не отвечает, если
не знал и по уведомлению принял меры) требует, чтобы (1) правила запрещали
нарушение, (2) была процедура уведомления и оперативного удаления.

Что делать: кнопка «Пожаловаться» на сообщение/ник → запись в
`reports` (кто, на кого, текст, время) → автоскрытие после N жалоб или ручное
решение админа; журнал решений хранить 1 год. Это же закрывает вопрос
«почему в 12+ игре мат в чате» при проверке.

### P1-3. Текстурапаки как канал нарушения прав

Пакеты позволяют заменить любой ассет (в том числе чужие арты). В EULA уже
написано, что за паки отвечает пользователь и что материалы игры
распространять нельзя. Усилить: при включении пака писать в лог источник,
а по жалобе правообладателя — блокировать пак и аккаунт.

### P2-1. Свои права: ТЗ и доказательство авторства

- Название и героев проверить в открытом реестре Роспатента — если «Cubic
  Battle» или персонаж пересекается с чужим знаком, ребрендинг дешевле иска.
- Зарегистрировать товарный знак (класс 9 — ПО, 41 — развлечения): госпошлина
  ~35–60 тыс ₽, срок 8–12 месяцев. Даёт право требовать компенсацию по
  ст. 1515 ГК (до 10 млн ₽ с поправками 2025 г.).
- Депонировать исходники и арт (нотариальный осмотр, сервисы депонирования,
  либо хеш + публикация в релизе). Git-история — доказательство, но слабее.
- Помнить про обратную сторону: компенсация по ст. 1301 ГК — 10 тыс–5 млн ₽
  **за каждый** неправомерно использованный объект. Клон-риски бьют больно,
  поэтому сходство с известными играми — это не «вдохновение», а цена.

### P2-2. Законопроект о видеоиграх № 795581-8

Пока не принят (рассмотрение переносилось, осенью 2026 обсуждается возврат).
Если примут в текущем виде — понадобится:
- идентификация игроков через ЕСИА / номер телефона / ЕБС;
- маркировка контента по категориям (насилие, страх, секс, мат, алкоголь,
  табак, наркотики, внутриигровые покупки);
- правила платежей и возвратов на русском;
- экспертиза игры и блокировка запрещённой информации.

Готовиться заранее стоит одним: **вынести авторизацию в отдельный слой**, чтобы
добавить ЕСИА/телефон без переписывания клиента. Сейчас вход зашит в
`auth_session.inc` вокруг Firebase — при переезде в РФ-ЦОД это всё равно
переписывается, удобный момент.

# Legal audit for Cubic Battle 4 (RU), 2026

Not a lawyer's opinion. This file tracks how the code and documents match Russian
law and where the simplest fixes are.

## Short verdict (after simplification)

- Only a nickname and a password are stored; no real names, e-mail or phone.
- Firebase is used worldwide; the user considers this acceptable because no
  real personal identifiers are collected. The registration screen and terms
  explicitly warn not to put a real name, surname, phone or e-mail into the nick.
- The `pumpkin_cube` gift has been removed; gift list is now 5 items.
- User-generated chat is filtered; a complaint button and admin panel exist.
- Age label 12+ is shown; parental PIN works locally (not transmitted).
- White vignette, blue ice blocks, Santa letter (bottom-right, "Be good in 2026
  and 2027! Love, Santa"), light random-cube-skin codecreeper and English-only
  code comments are implemented.

## What is done

- Nick + password only (fictitious `@cb4.game`-style allowed).
- Terms and registration screen warn against putting real personal data in nick.
- Account settings: change password, switch account, delete, second password,
  gifts; nick is never editable.
- Legal text (terms, privacy, consent) is present inside the game (`legal_text.inc`).
- Reports screen (`reports.inc`) is English; no long dashes in code comments.
- `docs/gifts.md` reflects the reduced gift list (pumpkin removed).
- `docs/pc-version.md` notes headless build (`build/pc/cb4_headless`) works.

## What remains if the project grows

- If real names/e-mail/phone are added later, a Russian-hosted database and a
  public privacy URL become required again.
- If free chat stays, an ORI notification and Russian-hosted chat logs may be
  needed under 149-FZ.
- A public operator e-mail and privacy page URL are needed for store listings.
