# Строим 3D как в Roblox Studio

DiScript теперь умеет то, ради чего в Studio открывают новый проект: ставить
детали, собирать из них модели, оживлять их анимацией и писать скрипты,
которые всё это двигают. Мира-«игры» с персонажем и физикой пока нет — есть
сцена, детали и скрипты к ним.

## Три понятия

**Part** — деталь. У неё есть форма, размер, цвет и положение.
**Model** — пустая группа. Всё, что в неё вложено, двигается вместе с ней.
**Сцена** — дерево из деталей и моделей, которое рисуется в окне просмотра.

## Первая сцена

```ds
# основание
base = scene.part("Base", "block")
base.size(20, 1, 20)
base.move(0, -0.5, 0)
base.color(110, 130, 100)

# дом: стена и крыша внутри модели
house = scene.model("House")

wall = scene.part("Wall", "block")
wall.parent(house)
wall.size(4, 3, 4)
wall.color(200, 170, 130)

roof = scene.part("Roof", "cone")
roof.parent(house)
roof.size(5, 1.8, 5)
roof.move(0, 2.4, 0)
roof.color(180, 70, 60)
```

`parent` вкладывает деталь в модель. После этого `house.move(10, 0, 0)`
увезёт и стену, и крышу — координаты детей считаются от родителя.

## Формы

| Имя | Что получится |
| --- | --- |
| `"block"` | коробка |
| `"sphere"` | шар (можно `"ball"`, `"шар"`) |
| `"cylinder"` | цилиндр |
| `"wedge"` / `"ramp"` | клин, трамплин |
| `"cone"` | конус |

```ds
ball = scene.part("Ball", "sphere")
ball.size(2, 2, 2)
```

## Что умеет деталь

| Метод | Значение |
| --- | --- |
| `move(x, y, z)` | поставить в точку (относительно родителя) |
| `rotate(x, y, z)` | повернуть, в градусах |
| `size(x, y, z)` | задать размеры |
| `color(r, g, b)` | цвет, 0–255 |
| `transparency(0..1)` | 0 — плотная, 1 — невидимая |
| `visible(false)` | скрыть, не удаляя |
| `parent(obj)` | вложить в модель |
| `remove()` | удалить вместе с детьми |
| `name()` | имя |
| `position()` | мировые координаты: `pos["x"]`, `pos["y"]`, `pos["z"]` |

`position()` возвращает **мировые** координаты — с учётом всех родителей.
Это то, что нужно для проверок «доехал ли объект».

## Анимация

```ds
# плавно доехать до (0, 4, 0), повернувшись на 90 градусов по Y
ball.animate(0, 4, 0, 0, 90, 0, 2.0)

# вращаться постоянно: 180 градусов в секунду
roof.spin(180)

# остановить
ball.stop()
```

Седьмой аргумент `animate` — скорость (единиц в секунду), восьмой — кривая:

| Кривая | Поведение |
| --- | --- |
| `"ease"` | плавно разгоняется и мягко останавливается |
| `"linear"` | равномерно |
| `"overshoot"` | проскакивает цель и возвращается |

Время двигает `scene.tick(dt)`. В редакторе его вызывает само окно
просмотра, а в обычном скрипте — вы:

```ds
for i in range(120):
    scene.tick(1.0 / 60.0)   # две секунды
```

Если тикать нечем, `animate` можно заменить на подсчёт:

```ds
for i in range(60):
    t = i / 60.0
    ball.move(0, t * 4, 0)
```

## Поиск и обход

```ds
found = scene.find("Ball")
if found:
    found.color(255, 0, 0)

print(scene.count())   # сколько объектов в сцене
scene.clear()          # начать заново
```

`scene.find` возвращает `None`, если имени нет — код `if found:` это ловит.

## Окно просмотра

Сцена рисуется рядом с кодом. Перетаскивание мышью вращает камеру, колесо
приближает. Камера сама наводится на то, что построил скрипт: большая
плоская плита считается полом и не мешает кадрировать дом.

## Чего пока нет

Честный список, чтобы не искать зря:

* **физики** — детали не падают и не сталкиваются, `anchored` пока только
  задумка;
* **событий** — нет `Touched`, `Clicked`, некому подписаться на столкновение;
* **света и теней** — есть общий фон и затемнение по дальности, но не
  источники света;
* **текстур** — только цвет.

Скрипты, модели и анимация уже работают; физика и события — следующий шаг.
