# Музыка

## Темы, созданные для проекта

Генератор `python3 tools/generate_music.py` собирает **только** три оригинальные
темы из нот: `lobbymusic.wav` (70 с), `winter_jingle.wav` (70 с) и
`duel_theme.wav` (45 с, бой Азума против Астры). Формат — 22050 Гц, стерео,
16-bit PCM WAV. Старая песня `azum_vs_astra.wav` и её reference MP3 удалены.

## Диско — настоящая опубликованная запись

Для события 1 используется **«Disco Medusae» — Kevin MacLeod
(incompetech.com)**, ISRC `USUAN1500041`, лицензия **CC BY 4.0**:
https://creativecommons.org/licenses/by/4.0/

Официальная страница:
https://incompetech.com/music/royalty-free/index.html?isrc=USUAN1500041

Это не нейросетевая и не процедурная музыка. Файл
`assets/audio/disco_medusae_kevin_macleod.mp3` содержит полную запись
(221.283265 с), сжатую до **885 568 байт (< 1 МБ)**: стерео MP3 32 kbps,
**22050 Гц**. Движок декодирует MP3 в PCM при загрузке через minimp3 (CC0).
Исходный MP3, точный источник, контрольные суммы и история изменений сохранены
в [`third_party/music/README.md`](../third_party/music/README.md).
Генератор нот этот файл **не создаёт и не перезаписывает**.

Проверить исходник и пересобрать сжатый MP3 можно скриптом
`python3 tools/import_disco_music.py` (нужен `ffmpeg` в PATH, переменная
`FFMPEG`, либо `pip install imageio-ffmpeg==0.6.0`). Для обычной сборки игры
FFmpeg не нужен: готовый MP3 уже лежит в ресурсах и работает без интернета.

Микшер зацикливает полную запись, пока активно диско. Музыка плавно появляется
и затухает при выключении события/выходе из боя, учитывает `music_volume` и
имеет приоритет над темами лобби, зимы и дуэли — одновременно они не играют.
Во время диско внизу боя видны название, автор и лицензия; нажатие открывает
страницу с полным указанием источника и лицензии. Атрибуция также поставляется
в `assets/audio/Disco-Medusae-NOTICE.txt` и каталоге `assets/audio/licenses/`.
