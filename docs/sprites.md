# 2D-игры на DiScript

Здесь про то, как собрать игру из картинок и скрипта: проект, спрайты,
игровой цикл, ввод. Пример целиком лежит в `examples/lobby`.

## Проект

Проект — это обычная папка. Ничего не спрятано в базе и не привязано к
устройству: скопировал папку — перенёс игру.

```
MyGame/
  project.json      имя, список картинок и скриптов
  scripts/main.ds   код
  sprites/player.png
```

Кнопка **+** наверху открывает список:

| Пункт | Что делает |
|---|---|
| Скрипт | новый файл `.ds` в `scripts/` |
| Картинка | открывает галерею, копирует файл в `sprites/` |
| Скрипт для спрайта | новый скрипт под управление картинкой |

Первая добавленная картинка создаёт рабочий скрипт: игра сразу запускается
и что-то делает, а не оставляет пустой файл.

`project.json` можно править руками. Он маленький и нарочно простой:

```json
{
  "version": 1,
  "name": "Lobby",
  "script": "scripts/main.ds",
  "sprites": [
    {"name": "player", "file": "sprites/player.png"}
  ]
}
```

Картинки понимаются в PNG и JPEG. JPEG важен: телефон фотографирует в него,
и картинка из галереи должна открываться без конвертации.

## Игровой цикл

Скрипт с функциями `update` и `draw` считается игрой. После RUN он не
заканчивается: `update(dt)` вызывается каждый кадр, `draw()` рисует кадр.
Кнопка RUN становится STOP и останавливает игру между кадрами.

```python
w = sprite.window()      # (ширина, высота) экрана

x = 100

def update(dt):
    global x             # без global присваивание создаёт локальную переменную
    x = x + 200 * dt     # dt — секунды с прошлого кадра

def draw():
    sprite.begin_frame()
    player.x = x
    player.y = 300
    sprite.add(player)
    sprite.draw_all()
```

`dt` — время кадра в секундах, а не в кадрах. Поэтому скорость не зависит от
того, 60 Гц у телефона или 120: `x = x + 200 * dt` это 200 пикселей в секунду.

**Про `global`.** Язык придерживается той же модели, что Python: присваивание
внутри функции создаёт локальную переменную. Счётчик кадров, позиция игрока,
очки — всё это меняется внутри функций, значит `global` нужен. Без него
`frames = frames + 1` читает ещё не заданную локальную и падает на первом кадре.

## Спрайты

| Что | Как |
|---|---|
| загрузить | `s = sprite.load("sprites/player.png")` |
| размер картинки | `s.width`, `s.height` |
| положение | `s.x`, `s.y` — левый верхний угол |
| центр вместо угла | `s.center = true` — тогда `x, y` это середина |
| поворот | `s.angle` — градусы, по часовой |
| масштаб | `s.scale = 2` |
| прозрачность | `s.opacity = 0.5` |
| отражение | `s.flip_x`, `s.flip_y` |
| порядок рисования | `s.z` — меньше значит ниже |
| показать | `s.visible = false` чтобы спрятать |

Квадратные скобки не нужны: `s.x` это обычное поле, как в C#.

`draw()` рисует то, что отмечено:

```python
sprite.begin_frame()   # начать кадр, сбросить прошлый список
sprite.add(player)
sprite.add(enemy)
sprite.draw_all()      # нарисовать всё добавленное по z
```

Пока `add()` не использовался ни разу, `draw_all()` рисует все загруженные
спрайты — так простая игра работает без лишних строк.

Текст поверх:

```python
sprite.text("СЧЁТ " + str(score), 24, 30, 255, 230, 110, 1.7)
#                    x    y    r    g    b  размер
sprite.measure("СЧЁТ", 1.7)   # (ширина, высота) — чтобы отцентровать
```

Полный экран `sprite.window()` возвращает список из двух чисел, `w[0]` и `w[1]`.

## Ввод

```python
def touchpressed(x, y):
    player.x = x
    player.y = y
```

| Функция | Когда вызывается |
|---|---|
| `touchpressed(x, y)` | палец коснулся экрана |
| `touchmoved(x, y)` | палец ведут |
| `touchreleased(x, y)` | палец отпущен |
| `keypressed(name)` | нажата клавиша (на ПК) |

Можно написать и по-лёвевски, `touchpressed(id, x, y)` — число аргументов
подстраивается под саму функцию.

## Что происходит при ошибке

Ошибка в `update` или `draw` останавливает игру и пишет строку в консоль с
номером строки и текстом. Редактор при этом продолжает работать: падение
игры не уносит недосохранённый код.

## Пример

`examples/lobby` — целый проект: лобби с надписью, игрок за пальцем, звёзды,
которые надо собрать, фон плиткой, счёт и таймер. Открывается в редакторе и
запускается как есть.
